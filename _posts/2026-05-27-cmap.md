# やりたいこと
imshowなどでヒートマップを描く時に, 値が0の場所の色を他と比べてわかりやすくしたい. 

# 使用言語と環境と
使用言語はPython, 必要なライブラリは以下. 
```python 
python 3.8.10 (アプデしないとですね......)
matplotlib 3.7.5
numpy 1.24.4
```

コードでは断りなく以下を使用する. 
```python
import numpy as np 
import matplotlib.pyplot as plt 
from matplotlib.colors import ListedColormap 
from matplotlib.patches import Patch
```

# 具体的な方法
指定色を透過する方法と, 指定値についてのmaskを作る方法がある. 

ここでは, 以下で定義する二変数正規分布を例として扱う. 

```python
nx, ny = 50, 50 
x = np.linspace(-5, 5, nx)
y = np.linspace(-5, 5, ny)
X, Y = np.meshgrid(x, y)
gaussian = np.exp(-(X**2 + Y**2))
```

そのままプロットすると以下のようになる. 
```
# --- そのままのプロット
plt.imshow(gaussian, cmap= cmap, origin = 'lower',
           extent = [x.min(), x.max(), y.min(), y.max()])
plt.colorbar()
plt.show()
```
![そのままのプロット]({{"/assets/images/2605/plot01.png" | relative_url }})

なんとも普通のプロットで, 中央の値が大きいということくらいはわかる. 

が, 周囲の値が0.0で埋まっているのか, 微小な値になっているのかは区別がつかない. \\
(特に0.1以下の値の差異は画像からは全く弁別できない)

## 方法1, cmapのalphaを直接編集する
matplotlibのカラーマップ`cmap`はRGBと不透明度の4情報を並べた配列として扱うことができ, 特定の値に対応する不透明度を0にすることができる.

例えば以下のようにして最小値に相当する色を透明にすることができる. 

```python
cmap = mlib.cm.viridis
colors = cmap(np.linspace(0, 1, 256))
colors[0, 3] = 0
alt_cmap =  mlib.colors.ListedColormap(colors)
alt_cmap
```

```
# --- 最小値の不透明度を0にしたプロット
plt.imshow(gaussian, cmap= alt_cmap, origin = 'lower',
           extent = [x.min(), x.max(), y.min(), y.max()])
plt.colorbar()
plt.show()
```
![不透明処理後のプロット]({{"/assets/images/2605/plot02.png" | relative_url }})

これで最小値よりも大きく, かつ0.1よりも小さい値の領域が図から確認できるようになった. 

## 方法2, set_badでmaskする
上記の方法では, カラーマップにおいて特定の順位の色を変えるくらいはできるが, 
値との対応が面倒であることや, 直感的な指定が難しい場合がある. 

そこで, 以下のようにカラーマップをmaskすることで, 指定した値について柔軟に処理を組むことができる. 
```python
masked = np.ma.masked_where(gaussian <= 1e-3, gaussian)
cmap = plt.cm.viridis
cmap.set_bad(alpha = 0.0)
plt.imshow(masked, cmap=cmap, origin = 'lower',
           extent = [x.min(), x.max(), y.min(), y.max()])
plt.colorbar()
plt.suptitle("maskで処理後")
plt.tight_layout()
plt.show()
```

![maskで処理したプロット]({{"/assets/images/2605/plot03.png" | relative_url }})

外れ値や欠損値に対処するのであれば, こちらの方が柔軟に対応できる. \\
（`np.ma.masked_where()`で条件指定できるため）

## （方法3, 特定の条件に該当する領域を別の色で塗る）
例えば $$[-1, 1]$$ の間で値をとるような分布についてのヒートマップを作る際に, 
 $$-1, 0, 1$$ の3点を強調して描画したいことがあるかもしれない. 

そのようなときは, 方法2を応用して以下のようにする方法もある. 

方法1, 2と同じデータについて, 1e-4以下, および0.9以上の領域をそれぞれ背景色（不透明度0）と赤で色分けする. 
```python
# 0を透明にするためにmask
masked_data = np.ma.masked_where(gaussian <= 1e-4, gaussian)

cmap = plt.cm.viridis.copy()
cmap.set_bad(alpha=0.0)

plt.imshow(masked_data, cmap=cmap)
plt.colorbar()

# data == 1 の場所だけ赤で上書き
red_mask = np.ma.masked_where(gaussian < 1-1e-1, np.ones_like(gaussian))

red_cmap = ListedColormap([
    (1.0, 0.0, 0.0, 1.0)
])
legend_elements = [
    Patch(facecolor="red", edgecolor="red", label="value > 0.9")
]
plt.legend(handles=legend_elements, loc="upper right")

pl

plt.imshow(red_mask, cmap=red_cmap)

plt.show()
```
![maskで処理したプロット]({{"assets/images/2605/plot04.png" | relative_url }})

但し, 色分けした領域についてはカラーバーで図示するよりは凡例に分けた方が見やすいかもしれない. 

# まとめる
ヒートマップで最小値を他と区別する（背景色と同色にする等）用途であれば, 
cmapのalphaを直接編集する方が便利. 

一方で, ヒートマップとして描画する対象が正負の値をとり, 0かどうかを区別したい場合など, 
特定の値や条件に基づいて色分けする場合では, 区別したい値についてのマスクで処理したほうが素直. 

同一のオブジェクトに対しての描画は基本的に上書きで行われるので, レイヤを意識して強調したい領域を分けて図示すると所望の描像が得られる.
