# BLUF

<!-- うまくいかなかったが, Graphical Lasso と部分相関ネットワークによる時系列解析を試した記録.  -->

## 何をしたかったか
- 多変量時系列データの相関関係をもとに, 時間変化するネットワーク構造として解析を行うこと.
- 特に, ネットワークのクラスタリングを通じて, 動的な同期減少を捉えること.

## やったこと
- 正規性を仮定したデータについて, Graphical Lassoによる解析を行い, 精度行列を得る.
- 得た精度行列から条件付相関を計算し, その相関係数に基づくグラフを構成する.
- グラフに対して, Louvain法によるクラスタリングを行うことで, 相関が存在するクラスタに分割する. 
- クラスタの時間変化を追跡するために, Jaccard指数に基づくクラスタidの同定を行い, 継承・消滅・新生に分類.
- 長時間生存しており, 時間発展とともに成長するような, 吸引的なクラスタが発生しているかどうかを確認.


## わかったこと
- データの正規性が保証されないような場合、そもそも結果の解釈が不正確である

## うまくいかなかったこと

- 時間窓ごとの共分散構造が十分安定しているとは言い難く,
  Graphical Lasso による推定結果そのものの安定性に疑問が残った.

- クラスタリング結果が,
  resolution parameter や threshold に比較的敏感であり,
  頑健な構造であるか判別が難しかった.

- Jaccard指数によるクラスタ追跡は実装容易性の面では有効であったが,
  merge / split に対して脆弱であり,
  長時間の同一性追跡が困難であった.

- 「吸引的クラスタ」の定義が曖昧であり,
  生存時間・サイズ・密度など,
  どの量をもって特徴量とするか整理できていなかった.

- 得られたクラスタ構造が,
  データ固有のノイズなのか,
  実際の動的構造を反映しているのか区別が難しかった.

## 次にやるなら

- 正規性・定常性の時間変化を先に評価する.
- window size と step size の感度解析を行う.
- Graphical Lasso 以外の相関推定法との比較を行う.
- Leiden法との比較.
- Temporal community detection の既存手法を調査.
- synthetic data に対するベンチマークを先に行う.
