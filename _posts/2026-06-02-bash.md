# やりたいこと
あるディレクトリ下の特定の表現を含む複数のファイル名を一括で変更したい。

# 設定等
```
main_dir/
    - data_file_01.h5
    - data_file_02.h5
    - data_file_03.h5
    - data_file_04.h5
    - analyzed_data_01.bin
    - analyzed_data_02.bin
    - analyzed_data_03.bin
sub_dir/
```

# 具体的な方法
main_dirのanalyzed_data_xx.binをsub_dir/に移す
```bash
for f in main_dir/analyzed_data_*.bin; do
    mv -- "$f" "sub_dir/${f}"
done
```

main_dirにあるdata_file_xx.h5ファイルをdata_XX.h5にrenameする
```bash
for f in data_file_*.h5; do
    mv -- "$f" "${f/file_/}"
done
```

# その他に
慣れないうちはいきなりすべてmvとかで処理する前に、一度echoを挟むとよいかもしれない。
上の例であれば、
```bash
for f in main_dir/analyzed_data_*.bin; do
    echo mv -- "$f" "sub_dir/${f}"
done
```
のようにして、出てきた出力が意図したとおりであれば、echoを外して再度実行すればよい。

mv のほかにも色々使えて、例えばcp を使ってバックアップとしてファイルをコピーしたり、du -fでファイルサイズを確認するなどできる。
# まとめる
bash上でもglobによるパターンマッチとfor文による処理を組むことができる。
